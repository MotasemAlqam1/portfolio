# Motasem Portfolio

A modern and responsive personal portfolio website built to showcase my projects, skills, and experience as a Junior Developer.

## About The Project

This portfolio website was developed using HTML5 and CSS3 with a clean, modern, and responsive design.

The website introduces me as a Junior Developer, presents my skills and technologies, showcases my projects, and provides contact information.

## Features

- Responsive design for desktop, tablet, and mobile devices.
- Hero section with introduction and call-to-action buttons.
- About Me section.
- Skills & Technologies section.
- Projects showcase.
- Contact section with contact form.
- Footer with useful links.
- CSS animations and hover interactions.
- Mobile navigation menu.
- Project links connected to GitHub repositories.

## Technologies Used

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Media Queries
- CSS Animations
- Font Awesome
- Google Fonts (Inter)
- Git & GitHub

## Website Sections

### Hero

Introduces me as a Junior Developer and provides quick links to the Projects and Contact sections.

### About Me

Provides a short introduction about me and highlights my skills and technologies.

### Projects

Showcases my projects with project descriptions, technologies used, and links to their GitHub repositories.

### Contact

Provides my contact information and a contact form for sending messages.

### Footer

Contains additional links and copyright information.

## Responsive Design

The website is designed to work across different screen sizes:

- Desktop
- Tablet
- Mobile

CSS Media Queries are used to adapt the layout and content for smaller screens.

## Animations & Interactions

The website includes CSS-based animations and interactive hover effects, including:

- Hero content animations.
- Profile image entrance animation.
- Button hover effects.
- Project image hover effects.
- Project link hover effects.
- Contact button hover effects.
- Navigation hover effects.
